# Trade_1

Интерактивная аналитическая платформа для исследования внешней торговли России, Китая и Индии (2017–2023).

## Возможности

- **Теоретические основы** — определения, правовая база, Инкотермс 2020
- **Семантический анализ** — NLP-анализ новостного фона (RSS, TextBlob, DeepSeek)
- **Статистический анализ** — динамика и структура торговли, теплота партнёрства
- **Результаты 2023** — итоги торговли с визуализацией
- **Прогнозы до 2030** — линейная регрессия, ARIMA, гибрид NN+RSS

## Быстрый старт

pip install -r requirements.txt
streamlit run app.py
